# 已保存学习曲线的核验说明

本页在 2026-09-25 直接读取仓库中的三个 NPZ 文件核对。下表来自已保存的聚合数组，本次没有重新运行训练。原始图像与 NPZ 保留；这些文件包含均值和标准差，没有逐种子的回报轨迹，因此不能独立重算各个种子的首次达标时间、持续达标时间或运行耗时。

`tools/benchmark.py` 中的 `solve_steps` 实际记录每次运行的最后环境步数，不是检测阈值后的首次解决步数。CartPole 的横轴由逐回合回报累计得到（每步奖励为 1）；不能把横轴本身叫作回合回报。

## CartPole 与 Pendulum

每行给出该算法自己保存的最后一个网格点；各行步数不同，不能直接用最后一列给算法排名。回报是平滑后的训练回报，不是独立评测集表现。标准差跨种子，不是置信区间。

| 环境 | 算法 | 最后网格步数 | 该点平均回报 | 该点标准差 |
| --- | --- | ---: | ---: | ---: |
| cartpole | REINFORCE | 108465 | 423.45 | 42.27 |
| cartpole | A2C | 240252 | 287.34 | 137.19 |
| cartpole | PPO | 34750 | 439.30 | 33.65 |
| cartpole | DQN (Double+Dueling) | 49028 | 341.27 | 157.08 |
| pendulum | DDPG | 8000 | -143.35 | 14.40 |
| pendulum | TD3 | 10000 | -210.10 | 62.33 |
| pendulum | SAC | 8000 | -200.37 | 68.27 |

例如 CartPole 的 PPO 最后保存点是 34,750 步、平均回报 439.30，不能写作“25 万步处达到 475”。Pendulum 的 TD3 最后点是 10,000 步，也不能标作共同的 8,000 步比较。单点平均回报越过阈值也不等于每个种子稳定解决任务。

## 如何阅读与复核

- `cartpole_curves.npz`、`pendulum_curves.npz`、`mappo_gridworld_curves.npz` 的键为算法名加 `_grid`、`_mean`、`_std`；它们是聚合曲线，不是逐种子原始数据。
- 现有基准脚本从零开始插值；第一次平滑观测之前的平段是端点填充，不能解释为真实零步评测或随机探索阶段。
- 原文记录为三个种子，但现有 NPZ 没有种子标识或逐种子数组；独立核验需要未来运行保存逐回合回报、种子、配置、代码版本和耗时。
- 比较样本效率时应固定评测规则，在各算法实际观测区间的交集上比较；训练结束和任务解决须分开统计。
- 第 01–04 章的基础实现可运行 `python tests/smoke_test.py` 检查；该检查不验证本页深度强化学习曲线。

## 重新运行

以下命令会重新训练并覆盖对应曲线产物。需要保留旧记录时，先使用独立工作副本。

```bash
python tools/benchmark.py --suite cartpole --seeds 3
python tools/benchmark.py --suite pendulum --seeds 3
python tools/mappo_curve.py --seeds 3 --iters 200
```

本页核对了现有数组与统计口径，未声称完成全部算法复现或验证未保存的运行过程。
